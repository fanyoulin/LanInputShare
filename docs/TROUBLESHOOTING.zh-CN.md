# LanInputShare 故障排查与已知限制

## 连接不上客户端

按以下顺序检查：

1. 客户端是否已经点击“保存并启动”，状态栏是否显示正在监听；
2. 主控填写的是客户端物理局域网 IPv4，而不是主控自己的 IP；
3. 主控与客户端端口是否一致，默认均为 TCP `24870`；
4. 客户端 IP 是否在重启、重新连接 Wi-Fi 后发生变化；
5. Windows 网络配置文件是否为“专用网络”；
6. 防火墙是否允许客户端在专用网络接收该端口；
7. Clash/VPN/TUN 是否把局域网地址送入代理隧道；
8. 两端是否使用了不同版本的程序目录。

PowerShell 可以从主控检查端口：

```powershell
Test-NetConnection <客户端IPv4> -Port 24870
```

如果提示“会话连接失败”或“拒绝连接”，先查看客户端是否弹出了新主控确认框。已信任设备会自动连接，新的设备身份需要在客户端本机确认。

## 退出后重新启动仍连不上

- 确认客户端进程已经重新监听，而不是只有窗口关闭但进程状态异常；
- 再次运行程序会恢复已有实例，不应启动多个副本；
- 主控会持续重试客户端，不要求固定启动顺序；
- 如果程序文件被更新，必须替换整个发行目录，不能只替换 EXE；
- 不要删除一端的身份目录后仍期望沿用旧信任。身份变化后应按新设备重新确认。

## 鼠标跨屏卡住或无法返回

1. 按 `Ctrl+Alt+Esc` 强制返回主控；
2. 在托盘菜单选择“返回主控”；
3. 检查主控与客户端位置是否真实相邻；
4. 外侧设备只能通过中间位置返回，布局中不能存在空的中间槽位；
5. 确认两端程序版本一致，并导出诊断。

断线或正常退出会释放按键并恢复主控光标。如果任务管理器强制结束后光标仍异常，可先在主控按 `Ctrl+Alt+Esc`，再重新启动程序。

## 快速移动不流畅

- 优先使用有线网络或 5 GHz/6 GHz Wi-Fi；
- 确认局域网流量没有经过 VPN/TUN；
- 大文件传输已经限速并让出控制消息，但较差的 Wi-Fi 仍可能增加延迟；
- 暂停其他下载、网盘同步或局域网大流量后再比较；
- 主控和客户端都应选择同一局域网对应的物理网卡。

## 文本、截图或文件无法同步

- 先复制一段普通文本，判断是整个剪贴板通道还是单一格式的问题；
- 截图必须进入 Windows 图片剪贴板；只复制某些软件内部对象时，可能没有标准 `CF_DIB/CF_DIBV5`；
- 文件需要先在来源设备复制，再切换到目标设备的资源管理器按 `Ctrl+V`；
- 文件不会在仅按 `Ctrl+C` 时立即传输；
- 如果目标目录存在同名文件，必须先处理覆盖提示；
- 某个程序长时间独占 Windows 剪贴板时，本次更新可能需要重新复制；
- 诊断日志不会记录实际剪贴板文字、图片内容、文件内容或私钥。

## 看不到文件传输进度

这是预期行为：完成时间不足约 1 秒的传输不会显示浮窗。较大文件开始传输约 1 秒后，浮窗会显示在当前鼠标所在屏幕顶部；完成后自动消失，失败时会停留更久以便阅读错误。

## 托盘中没有图标

- 点击关闭前，程序会检查系统托盘是否可用；不可用时会保持窗口打开；
- Windows 可能把图标收进“隐藏的图标”区域；
- 再次运行 `LanInputShare.exe` 可以恢复已有窗口；
- 如果进程已经退出，重新运行后会按已保存配置启动。

## 管理员窗口和 UAC

客户端可以在“增强控制”一栏安装独立的高权限输入助手：

- 未启用或助手暂不可用时，程序自动使用标准控制，管理员窗口不能操作；
- 显示“增强控制可用”时，可以操作普通桌面上的管理员窗口，主程序和网络模块仍为普通权限；
- 首次启用或升级修复时会请求一次 UAC，日常启动不会重复请求；
- 显示“需要修复”通常表示主程序路径、哈希、助手哈希或协议版本发生变化，请使用同一完整发行目录点击修复；
- 助手安装在 `%ProgramFiles%\LanInputShare`，清单只批准当前用户、会话和指定主程序；
- UAC 安全桌面、登录界面和锁屏界面仍然不能通过本程序控制；
- 不建议为了本程序关闭 UAC。UAC 安全桌面出现时，请使用目标电脑的物理键鼠确认，返回普通桌面后会自动恢复。

如果启用/修复失败，先确认发行目录中的 `LanInputShare.exe` 与 `LanInputShareInputHelper.exe` 均存在，并用 `SHA256SUMS.txt` 核对哈希。不要从不同版本目录混合复制文件。

## 防火墙建议

只为客户端在 Windows“专用网络”配置文件开放所用 TCP 端口。不要对“公用网络”开放，也不要在路由器上做公网端口转发。

如果需要手动建立规则，请在“高级安全 Windows Defender 防火墙”中确认作用域、网络配置文件和程序路径，不要直接复制来源不明的管理员命令。

## 重置配置或信任

退出程序后，可以按需要处理 `%LOCALAPPDATA%\LanInputShare`：

- 只重置界面配置：备份后删除 `config.json`；
- 只清理暂存：确认没有传输后删除 `staging`；
- 完全重置：删除整个目录。

完全重置不可恢复，会生成新的设备身份，其他电脑会把它视为新设备并重新要求确认。

## 已知限制

- 仅支持 Windows 10/11 64 位；
- 暂不支持 macOS、Linux；
- 最多三台电脑，一台主控和两台客户端；
- 每台电脑只支持一个显示器；
- 只支持同一局域网，不提供公网中转；
- 不支持 UAC 安全桌面、登录界面和锁屏；
- 不提供驱动或 Session 0 Windows 服务；增强助手仅在当前交互用户会话运行；
- 不能替代远程桌面的画面、声音和会话功能；
- 剪贴板图片支持 Windows 标准 DIB/DIBV5，不保证所有应用私有格式都能转换；
- 网络质量较差时，大文件传输仍可能增加键鼠延迟。
