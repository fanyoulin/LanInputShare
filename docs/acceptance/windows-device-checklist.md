## 连接与身份

- [ ] 客户端先启动并监听所选物理网卡。
- [ ] 主控只连接配置中的客户端 IPv4，没有局域网广播或误连。
- [ ] 新主控在空闲客户端上弹出设备名称和短指纹确认。
- [ ] 拒绝或关闭确认框后不写入信任。
- [ ] 已确认的同一主控重启后可自动连接。
- [ ] 客户端已连接时，第二个主控不会抢占会话。
- [ ] 两端不同退出顺序、正常退出和强制结束后均可重新连接。

## 键盘、鼠标与布局

- [ ] 主控分别位于上、下、左、中、右时，合法布局均可保存。
- [ ] 客户端可以拖动到其他合法位置并立即生效。
- [ ] 上、下、左、右相邻边缘都能双向跨屏。
- [ ] 跨屏落点按两块屏幕的相对位置衔接，没有固定跳到中间或角落。
- [ ] 每种使用中的方向至少往返 20 次，没有卡边或返回旧坐标。
- [ ] 快速画圆、拖窗、滚轮和连续点击可用。
- [ ] `Ctrl+Alt+Esc` 能立即返回主控。
- [ ] `Ctrl+Alt+1/2/3` 能切换到对应的已占用布局槽位。
- [ ] 按住字母键或鼠标键时断网，双方均无卡键。

## 剪贴板与文件

- [ ] 中英文、Emoji 和换行文本双向复制粘贴成功。
- [ ] 主控截图能在客户端粘贴为图片。
- [ ] 客户端截图能在主控粘贴为图片。
- [ ] 小文件跨设备复制粘贴成功且不显示多余进度浮窗。
- [ ] 大文件传输超过约 1 秒后显示百分比、速度和取消按钮。
- [ ] 文件夹和多个文件均可传输，目标文件大小与哈希正确。
- [ ] 同名冲突在文件内容传输前提示覆盖、跳过或取消。
- [ ] 取消传输后不留下可见的损坏目标文件。
- [ ] 跨设备剪切不会删除来源文件。
- [ ] 大文件传输期间键盘、鼠标和紧急返回仍可用。

## 窗口、托盘与诊断

- [ ] 关闭按钮提供最小化到托盘和退出，弹窗 X 表示取消。
- [ ] 最小化后托盘图标可见，单击或双击可以恢复窗口。
- [ ] 再次运行程序会恢复已有窗口，不产生无响应的第二实例。
- [ ] 托盘的暂停、返回主控、打开设置、导出诊断和退出可用。
- [ ] 配置、IP、端口和布局在退出后仍保留。
- [ ] 导出的诊断包不包含私钥、剪贴板内容或文件内容。
