# LanInputShare 中文使用说明

## 1. 准备工作

使用前确认：

- 所有电脑均为 Windows 10/11 64 位；
- 每台电脑只使用一个显示器；
- 一台电脑作为主控，最多两台作为客户端；
- 所有电脑位于同一局域网；
- 客户端最好使用固定 IPv4，或在路由器中设置 DHCP 地址保留；
- 所有电脑使用同一版本的完整程序目录，不要只复制 `LanInputShare.exe`。

默认使用 TCP `24870`。如果更改端口，主控布局中填写的端口必须与对应客户端一致。

## 2. 客户端配置

建议先配置并启动客户端。

1. 运行 `LanInputShare.exe`。
2. 设备名称默认是本机 Windows 计算机名，可按需修改。
3. 角色选择“客户端”。
4. 网卡默认“自动选择物理网卡”；也可以手动选择实际连接局域网的以太网或 Wi-Fi。
5. 确认监听端口，默认是 `24870`。
6. 点击“保存并启动”。

客户端不填写主控 IP，也不设置自己的屏幕位置。它只在选定网卡上监听，等待主控主动连接。

### 增强控制

普通运行主程序即可完成日常控制。若需要操作客户端普通桌面上的任务管理器、管理员终端等高权限窗口：

1. 在客户端“增强控制”一栏点击“启用增强控制”；
2. Windows 仅在首次启用或版本变化后修复时请求 UAC；
3. 确认后，高权限输入助手按当前用户登录自动启动，主程序本身仍保持普通权限；
4. 状态显示“增强控制可用”后即可操作普通桌面上的管理员窗口。

状态含义：

- “未启用”：仍可控制普通窗口；
- “增强控制可用”：普通窗口和普通桌面上的管理员窗口均可控制；
- “安全桌面”：远程输入暂停，必须在客户端本机确认 UAC；
- “暂不可用”：自动降级控制普通窗口并后台重连助手；
- “需要修复”：主程序或助手版本/哈希变化，点击修复并确认一次 UAC。

不再需要时可点击“移除增强控制”。状态刷新、网络重连和日常启动都不会自动弹出 UAC。

## 3. 主控配置

1. 填写设备名称。
2. 角色选择“主控”。
3. 选择承载局域网地址的物理网卡。
4. 在“本机位置”中选择主控实际所在的上、下、左、中或右。
5. 选中其他槽位，填写对应客户端的 IPv4 和端口。
6. 点击“保存并启动”。

主控最多配置两个客户端。同一个 IP 或位置不能重复。

### 布局规则

布局采用十字相邻关系：

```text
        上
左      中      右
        下
```

- 中间可以与上、下、左、右相邻；
- 外侧位置只与中间相邻；
- 多台设备时必须通过“中”连接，不能跨越空槽位；
- 主控可以位于任意一个槽位；
- 已配置的客户端可以在布局中拖到其他可用槽位，运行中的布局会立即更新。

## 4. 首次连接与信任

首次出现的新主控连接时，客户端会恢复窗口并显示：

- 主控设备名称；
- 证书短指纹；
- 是否信任的确认按钮。

请在客户端电脑上核对后选择是否信任。确认过的同一设备以后可以自动连接；从未确认过的新主控仍会再次询问。客户端正在被其他主控使用时，不会同时接受第二个主控。

身份信息保存在 `%LOCALAPPDATA%\LanInputShare\identity`，信任记录保存在 `trusted-devices.json`。复制程序目录不会复制身份和信任关系。

## 5. 键盘和鼠标

连接成功后，将鼠标从当前屏幕与相邻设备相接的一侧移出，即可切换设备。跨屏坐标会根据两边分辨率按比例映射。

默认快捷键：

| 快捷键 | 功能 |
|---|---|
| `Ctrl+Alt+Esc` | 无论当前在哪台客户端，立即返回主控 |
| `Ctrl+Alt+1` | 切换到第 1 个已占用布局槽位 |
| `Ctrl+Alt+2` | 切换到第 2 个已占用布局槽位 |
| `Ctrl+Alt+3` | 切换到第 3 个已占用布局槽位 |

快捷键槽位按“上、左、中、右、下”顺序跳过空位排列。托盘菜单也提供“返回主控”和“暂停共享”。

如果客户端断线或程序退出，主控会释放当前按键和鼠标状态，并恢复本地控制。

## 6. 文本与截图剪贴板

文字和 Windows 图片剪贴板会在已连接设备间自动同步：

1. 在任意设备复制文字或截图；
2. 切换到另一台设备；
3. 在目标程序中正常粘贴。

支持 Unicode 文本以及 Windows `CF_DIB`、`CF_DIBV5` 图片格式。图片会压缩并分块传输，超过安全大小限制的图片会跳过并在状态栏提示。

普通文件复制不会仅因按下 `Ctrl+C` 就立刻占用大量带宽；文件内容要等到目标设备按下 `Ctrl+V` 后才开始传输。

## 7. 文件和文件夹复制

1. 在来源设备选中文件或文件夹并复制。
2. 将键鼠切换到目标设备。
3. 在资源管理器的目标文件夹中按 `Ctrl+V`。
4. 程序先检查目标路径与同名冲突，再开始传输。

出现冲突时可选择：

- “覆盖全部”：替换冲突项目；
- “跳过冲突”：只传输没有冲突的项目；
- “取消传输”：不传输任何内容。

传输期间：

- 数据先写入 `.part` 临时文件；
- 大小和 SHA-256 校验通过后才进入目标剪贴板并执行粘贴；
- 耗时不足约 1 秒的小文件通常不显示浮窗；
- 较大的文件会在当前鼠标所在屏幕顶部显示百分比、速度和取消按钮；
- 跨设备剪切按复制处理，不删除来源文件。

## 8. 关闭、托盘和重新打开

点击主窗口右上角 X 时，可以选择“最小化到托盘”或“退出程序”。选择框右上角 X 表示取消关闭。

最小化后可以通过以下方式恢复：

- 单击或双击系统托盘中的程序图标；
- 再次运行 `LanInputShare.exe`，已有实例会恢复窗口。

托盘菜单提供：

- 暂停/恢复共享；
- 返回主控；
- 打开设置；
- 导出诊断；
- 退出。

真正退出时，程序会先恢复本地键鼠状态并关闭网络会话。配置会保留，下次启动仍使用之前的 IP、端口和布局。

## 9. Clash、VPN 与 TUN

本程序不读取系统代理，也不会自动修改 Clash/VPN/TUN、路由表或 Windows 防火墙。

代理开启时建议：

1. 在代理软件中启用“绕过局域网/私有地址”；
2. 确保客户端 IPv4 走以太网或 Wi-Fi 物理网卡；
3. 两端都选择实际承载该 IPv4 的物理网卡；
4. 不要填写 TUN、Wintun、WireGuard、Hyper-V、WSL 或回环网卡地址。

## 10. 诊断与数据位置

主窗口和托盘均可导出经过过滤的诊断包。命令行也可执行只读诊断：

```powershell
LanInputShare.exe --diagnose
```

用户数据目录：`%LOCALAPPDATA%\LanInputShare`。分享日志或诊断包前仍应自行检查是否包含不希望公开的设备名、IP 或文件名。
